# AIHR Context

## Purpose

AIHR evaluates and monitors AI-assisted hiring recommendations. The current product compares AI and human recommendation funnel performance, supports segmented analysis, and provides monitoring signals for effectiveness and drift-style changes.

## Core Vocabulary

- **Recommendation source**: The origin of a candidate recommendation, such as AI or human.
- **Hiring funnel**: The sequence of recruiting stages used to compare conversion behavior.
- **Effectiveness**: The measured quality or business value of recommendations across funnel stages.
- **Monitoring**: Repeated checks over time for changes in key metrics.
- **Model version**: The recommendation model or baseline rule version attached to a recommendation, used to segment effectiveness and monitoring.
- **Recruiter team**: The consultant or recruiting team responsible for follow-up, used to segment operational performance.
- **Mature queue**: Recommendations old enough to have had a fair opportunity to complete delayed funnel stages.
- **30-day qualified interview rate**: Mature recommendations that reached interview within 30 days of recommendation, divided by mature recommendations.
- **Unresolved alert**: A still-open monitoring signal for a filtered population, such as a material interview-rate drop.
- **Propensity score adjustment**: An observational adjustment method that estimates how likely a recommendation was AI-sourced from observed covariates before comparing outcomes.
- **Common support**: The overlapping propensity score range where AI and human recommendations are both represented.
- **Extreme weight handling**: Weight clipping used to limit unstable inverse-probability weights in adjusted observational comparisons.
- **Standardized mean difference (SMD)**: A balance diagnostic comparing covariate differences before and after adjustment.
- **Population Stability Index (PSI)**: A numeric-feature drift metric comparing binned baseline and current distributions.
- **Jensen-Shannon Divergence (JSD)**: A categorical-feature drift metric comparing baseline and current category distributions.
- **Recommendation score drift**: A monitoring signal comparing baseline and current recommendation score levels.
- **Diagnostic conclusion**: A monitoring finding with a problem category, evidence metric, time range, sample size, and dimension breakdown.
- **Problem category**: The explanation class for a diagnostic conclusion: data issue, traffic structure, model, recruiter operation, or hiring process.
- **Data quality check**: A structured API result for a named data reliability rule, including status, severity, evidence metric, affected count, sample size, time range, and machine-readable details.
- **Layer freshness**: Record count and latest update timestamp for a dimension, fact, or mart layer used to judge whether analytics data is complete and current.
- **Synthetic demo data**: Seeded demonstration data used by the current app instead of real candidate or company records.
- **Real job-market data**: Externally sourced job posting data used to represent the hiring market; it does not contain private candidate funnel outcomes.
- **Experimental funnel outcome**: Privacy-safe recommendation, interview, offer, or hire outcome generated by AIHR for method validation when real ATS outcomes are unavailable.
- **Metric dictionary**: Shared definitions for analytics fields and measurements. See `docs/metric_dictionary.md`.

## System Shape

- `src/aihr/api/main.py` exposes the FastAPI application.
- `src/aihr/services/analytics.py` contains dashboard analytics behavior over event-level recommendation facts so all pages can share date, source, job, region, model version, and recruiter team filters.
- `src/aihr/services/marts.py` builds reusable analytics marts for daily funnel, cohort maturity, AI effectiveness, drift, and monitoring alert rollups.
- `src/aihr/models.py` and `src/aihr/schemas.py` define persistence and API data shapes.
- `app/` contains the Streamlit dashboard and API client.
- `tests/` contains pytest coverage for analytics, API behavior, and seed data.
