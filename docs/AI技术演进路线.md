# AIHR AI 技术演进路线

## 阶段 1：规则摘要

基于结构化分析上下文生成结论、证据、风险和建议；当模型不可用时退回规则结果。重点是指标口径稳定、结果可复现、低成本运行。

## 阶段 2：可解释 RAG

检索指标字典、数据模型、架构文档和运行手册。每个片段返回 `文档路径#段落锚点`，回答必须携带引用。当前 30 条离线评估集的结果为：Recall@3 0.8846、引用正确率 0.8846、无答案拒答率 1.0。

## 阶段 3：安全工具调用

仅开放 `search_docs`、`inspect_schema`、`run_readonly_sql` 和 `get_quality_status`。SQL 使用 AST 解析，限制为单条 SELECT、表白名单和最多 100 行；提示注入、敏感字段、DDL/DML 和非白名单表直接拒绝。

## 阶段 4：多步分析 Agent

下一阶段才接入模型规划器。规划器输出必须经过服务端 schema 校验，最多执行固定步数，并记录问题、工具、参数、耗时、结果规模与拒绝原因。上线门槛包括：工具选择准确率、SQL 执行成功率、敏感数据泄露率、平均成本和 P95 延迟。

当前项目只宣称完成前三阶段的原型，不宣称具备自主执行或生产级多 Agent 能力。
