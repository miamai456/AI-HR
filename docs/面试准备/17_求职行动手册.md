# 第 17 课（补充）：求职行动手册（投递 → 面试 → 拿到 offer）

> 把 00-16 全部材料串成一份**可执行计划**。照着做，不慌。

## 一、岗位组合策略（3 类一起投）

| 类型 | 例子 | 占比 | 心态 |
|---|---|---|---|
| **主力**：商业分析/经营分析/初级数据分析师 | 美团商业分析岗、各厂 DA | 70% | 认真准备、主力投入 |
| **冲刺**：数据科学/算法方向 | 上一个美团数据科学岗 | 20% | 投了练手，不过不气馁 |
| **保底**：业务运营/产品运营含数据职责 | 运营分析、策略运营 | 10% | 先上岸再跳 |

> 原则：**海投有选择地投**——同一家公司别一天投 5 个岗，投 1-2 个最匹配的。

## 二、投递前 7 项检查（每份简历投出前过一遍）

1. [ ] 简历项目描述**按该 JD 定制**（商业分析岗用 16 课版本，数据科学岗用 13 课版本）
2. [ ] 开头"求职意向"和 JD 关键词一致（如"商业分析/经营分析"）
3. [ ] 技术栈写在显眼处：Python / SQL / pandas / scikit-learn / FastAPI / Streamlit
4. [ ] 数字具体：10 万推荐、60 万事件、12 项质量检查、76 项测试
5. [ ] 附上项目可运行说明（README 一键启动 + SQLite 兜底，面试当场能跑）
6. [ ] 求职信（见下节）针对岗位写了 3 句话，不是群发模板
7. [ ] 错别字、格式（PDF）、文件名规范（姓名-岗位-城市）

## 三、求职信模板（投递邮件/系统内 150-200 字）

> 主题：应聘商业分析岗（数据科学方向）- 姓名

**正文**（针对第二个 JD 版）：

> 您好，我对美团商业分析岗（数据科学方向）非常感兴趣。我理解这个岗位的核心是把业务问题翻译成数据问题、为经营决策提供科学方案——这正是我一直在做的事。
>
> 我独立完成了一个 AI 招聘推荐效果评估系统：业务方问"AI 推荐是否更有效"，我没有直接给数字，而是拆解出选择偏差和结果滞后两个陷阱，用统一口径、成熟队列、倾向得分调整（SMD 验证平衡）建立了一套可验证的分析框架，并把结论落到"下一步查哪里"的业务动作上。整个过程就是一次完整的"业务问题 → 分析方案 → 决策依据"闭环。
>
> 我掌握 Python/SQL 分析技能，理解 A/B 实验设计（样本量、AA 检验、SRM、多重比较），并在项目中实践了大模型辅助数据分析（结构化上下文 + 可信度信封控制幻觉）。我的项目可现场演示，期待有机会与您交流。

## 四、面试流程预期（基于公开面经，各团队可能有差异）

> 来源：[美团商业分析面经（牛客）](https://www.nowcoder.com/discuss/634830026592026624?urlSource=sitemap)、[已offer入职面经（牛客）](https://www.nowcoder.com/feed/main/detail/4128c8dc619e41039fa67fce8c734d5d?toCommentId=15680380)、[商业分析面经（wondercv）](https://www.wondercv.com/community/11110.html)、[商业分析一面+二面面经（wondercv）](https://www.wondercv.com/community/14265.html)

常见轮次（校招/社招初级常见组合）：

| 轮次 | 考什么 | 你的弹药 |
|---|---|---|
| 笔试/测评 | 行测、SQL 题 | 15 课 SQL 8 题 + 刷题 |
| 群面（校招常见） | 商业 case 讨论（如"外卖早餐怎么提升"） | 16 课策略题框架：拆解→假设→方案→验证 |
| 业务一面 | 项目深挖 + 1-2 道 case | AIHR 商业叙事 + 16 课 |
| 业务二面/交叉 | 更深的 case + 思维题 | 16 课 + 15 课指标异动 |
| HR 面 | 动机、稳定性、薪资 | 准备"为什么来美团/为什么这个岗" |

> ⚠️ 不保证每家公司都这 5 轮（有的一轮业务面就定），但**题型**基本就是这些：SQL、case、项目深挖、行为题。

## 七、被拒了怎么办（心态建设）

1. **被拒 ≠ 你不行**：尤其是冲刺岗，简历关没过很正常，不用自我怀疑；
2. **每次面试后复盘**：哪题卡住 → 回对应材料补 → 下次改进；
3. **批量投递**：面试是概率游戏，投 20 个有 5 个面试、1-2 个 offer 是正常节奏；
4. **保底先上岸**：能力是在工作中长的，先进门再升级。
