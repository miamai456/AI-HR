## 一、A/B 实验是什么（30 秒版）

随机把用户/样本分成 **A 组（对照）** 和 **B 组（实验）**，只对 B 组施加改动，比较两组业务指标差异。

**为什么是因果金标准**：随机化让两组在**所有**可观测和不可观测特征上期望一致 → 差异只能归因于改动 → 可以谈因果。

**和 AIHR 的关系（面试桥接句，背熟）**：
> "我的 AIHR 项目用的是观察性数据，用倾向得分 IPTW 做关联分析，并明确标注非因果——这让我深刻理解了'观察性 vs 实验性'的边界。如果业务允许，我会把 AI 推荐的效果验证迁移到随机分流实验：AI 推荐为实验组、人工为对照组，AA 检验验证分流、先算样本量保证功效，从而得到因果结论。"

## 二、核心概念（小白版术语表）

| 概念 | 人话 | 面试点 |
|---|---|---|
| 显著性水平 α | 允许的"假阳性"概率，通常 0.05 | "错误地宣称有效果的概率" |
| 检验功效 Power | 真有效果时能测出来的概率，通常 80% | "测不出=浪费实验" |
| MDE | 想检测的最小效果量 | "MDE 越小，样本量越大" |
| p-value | 假设没效果，看到当前差异的概率 | **不是"有效果的概率"**，别答错 |
| AA 检验 | 两组都放同版本，验证分流随机 | 基线可比才能信实验结果 |
| SRM | 分流比例偏离预期（如 52/48） | 数据失配=实验作废信号 |
| 置信区间 | 效果的不确定性范围 | 比 p 值信息量大 |
| 多重比较 | 看很多指标/多次偷看数据 | 假阳性膨胀，需校正 |
| 新奇效应 | 新功能短期好奇心高估效果 | 实验要跑够时长 |
| 网络效应 | 实验组影响对照组（社交产品） | 单元随机化的经典难题 |

## 三、样本量怎么算（能讲逻辑就够）

**简化公式**（每组）：

```text
n ≈ 2 × (z_{α/2} + z_power)² × p(1-p) / MDE²
```

- p = 基线转化率；MDE = 最小可检测差异；α=0.05 → z=1.96；power=0.8 → z=0.84

**例子**：基线面试转化率 p=0.2，想检测 MDE=1pp：
n ≈ 2 × (1.96+0.84)² × 0.2×0.8 / 0.01² ≈ **25,000 人/组**

**讲逻辑（面试加分）**：MDE 越小、基线方差越大、α 越小、power 越高 → 样本越多。

**实验时长**：样本量 ÷ 日均流量，还要考虑周末/节假日波动、新奇效应（新功能至少跑 1~2 个完整周期）。

## 四、实验全流程（面试常问"设计一个实验"）

1. **明确假设**：H0 无差异 / H1 有差异（方向）
2. **选指标**：主指标（决策依据）+ 护栏指标（不能变差）+ 辅助指标（解释机制）
3. **分流设计**：单位（用户/设备/会话）+ 分层随机化（减少方差）
4. **样本量与时长**：套公式 + 流量预算
5. **AA 检验**：分流前验证两组基线可比
6. **运行与监控**：SRM、数据质量、提前终止规则
7. **分析**：显著性 + 效应量 + 置信区间 + 多重比较校正
8. **决策**：上线 / 回滚 / 继续跑；评估长期效应

## 五、高频面试题与标准答案

**Q1 设计一个实验验证"AI 推荐"是否有效？**
答：随机分流候选人或职位 → A 组人工推荐、B 组 AI 推荐 → 主指标 30 天面试率、护栏指标联系率（不能牺牲触达）→ 按基线 19.4% 和 MDE 1pp 算样本量（约 2.5 万/组）与时长 → AA 验证 → 分析显著性+置信区间 → 决策。同时监控 AI 推荐是否只挑简单岗位（用 SMD 看分流后特征平衡，把 AIHR 的知识用上）。

**Q2 p-value 是什么意思？**
答：假设真实没效果，观察到当前或更极端差异的概率。p<0.05 只能说"差异不太像随机"，**不是"95% 概率有效果"**。

**Q3 实验没达到显著性，能说"没效果"吗？**
答：不能。要看功效是否足够：功效不足时是"测不出来"而不是"没效果"。正确做法：报告置信区间，说明效果的可能范围。

**Q4 为什么做 AA 检验？**
答：验证分流随机性、基线可比。AA 有显著差异说明分流系统或数据有问题，实验结果不可信。

**Q5 SRM 是什么？怎么发现？**
答：样本比率失配——实际分流比例偏离设定（如 50/50 变成 48/52）。检查方法：每日监控分流计数，用二项检验看偏差是否显著；出现 SRM 要排查埋点、分流系统、用户 ID 漂移，严重时实验作废。

**Q6 同时看 10 个指标，怎么控制假阳性？**
答：主指标在实验前锁定；探索性指标用 FDR 控制（Benjamini-Hochberg）或 Bonferroni（α/次数）；避免"数据显著了才想起来看"（p-hacking）。

**Q7 观察到 +1% 显著提升，能直接上线吗？**
答：先看护栏指标有没有被破坏、AA 是否通过、SRM 是否正常、新奇效应是否排除；再看效应量业务上是否值得（显著性 ≠ 业务重要性）。

## 六、观察性分析 vs 实验（AIHR 衔接题，面试大概率问）

| 维度 | AIHR（观察性） | A/B 实验 |
|---|---|---|
| 选择偏差 | 存在，用倾向得分调整 | 随机化消除 |
| 未观测混杂 | 无法排除 | 随机化后期望平衡 |
| 因果结论 | 不能（关联分析） | 可以 |
| 成本 | 低，用存量数据 | 高，需流量与时长 |
| 适用 | 无法实验时的近似 | 能分流时的金标准 |

**迁移故事（背熟）**："AIHR 让我建立了严谨的因果思维：知道观察性结论的边界（未观测混杂、SMD 只能验证已观测变量），所以当业务问'AI 是否真的更好'时，我的第一反应不是再看图，而是问'能不能分流做实验'。倾向得分的变量选择（经验/岗位/地区/团队）直接可以复用为实验的协变量，做分层随机化降低方差。"
