## 一、项目深挖题（基于 AIHR，但按这个 JD 的镜头）

**⭐Q1 你的项目哪里体现了"因果思维"？**
答：两点。① 我明确区分观察性关联与因果——AI 和人工推荐不是随机分配，直接比面试率有选择偏差，所以我用倾向得分 IPTW 调整已观测协变量、用 SMD 验证平衡，结论只叫"调整后的关联差异"，不宣称因果；② 当业务问"AI 是否真的更好"时，我的第一反应是"能不能分流做实验"，因为只有随机化才能消除未观测混杂。

**Q2 为什么不直接做 A/B 实验？**
答：项目是离线历史数据，没有真实产品流量可分流，所以用倾向得分做观察性近似；但方法选择上我知道实验才是金标准——倾向得分的协变量（经验/岗位/地区/团队）可以直接复用为分层随机化的分层变量，实验设计我已经系统学过（样本量、AA 检验、SRM、多重比较）。

**⭐Q3 倾向得分和随机实验的差异，用一个例子说明？**
答：随机实验里，经验高的候选人在两组出现概率期望相同，差异只归因于 AI 与否；观察性数据里 AI 组经验显著更高（SMD 0.58），我加权后把 SMD 降到 0.013 模拟"伪随机"。但未观测混杂（候选人真实质量）无法用加权消除，而随机化可以。

**Q4 如果让你把 AIHR 升级成实验平台，第一步做什么？**
答：① 设计分流方案（候选人/职位为单元、分层随机化）；② 确定主指标（30 天面试率）+ 护栏指标（联系率、回复率）；③ 按基线 19.4% 和 MDE 1pp 算样本量（约 2.5 万/组）与时长；④ 上线前 AA 检验；⑤ 运行期监控 SRM；⑥ 分析用显著性+置信区间+多重比较校正。

## 二、因果推断专业题（这个岗位的核心区）

**⭐Q5 什么是混杂？举例。**
答：混杂是同时影响处理（AI 推荐与否）和结果（面试）的第三变量。例：候选人经验——AI 倾向推荐高经验的人，高经验本身也更容易进面试，于是"AI 效果好"可能是"经验高"造成的假象。

**Q6 什么是"对撞变量"（collider）？为什么建模时不能随便控制变量？**
答：对撞变量同时受处理和结果影响。如果按它分层或控制它，会在处理和结果之间打开一条虚假路径（选择偏差）。所以因果建模时变量选择要基于因果图（DAG），而不是"把所有变量都放进回归"。

**⭐Q7 你了解哪些因果推断方法？各自适用场景？**
答：① 随机实验（A/B）：金标准，能分流时用；② 倾向得分匹配/加权（IPTW）：处理是二值、有大量可观测混杂时；③ 双重差分（DID）：政策/产品上线前后对比 + 对照组，处理是群体级、平行趋势假设；④ 工具变量（IV）：存在未观测混杂但有工具时；⑤ 断点回归（RDD）：处理由阈值决定时。AIHR 用的是第②种。

**Q8 双重差分（DID）的核心假设？**
答：平行趋势假设——如果没有处理，实验组和对照组的趋势一致。验证方法：看处理前多期趋势是否平行（事件研究图）。

**Q9 什么是 SRM？和因果推断有什么关系？**
答：样本比率失配。分流比例偏离设定说明分流/数据有问题，此时"两组可比"的前提被破坏，因果推断不成立。发现 SRM 要先排查，不能继续分析。

## 四、大模型 × 数据科学题（你的差异化优势区）

**⭐Q10 你怎么用大模型辅助数据分析？举例。**
答：AIHR 里搭了 LLM 分析助手：先由结构化 API 算好指标，把压缩后的上下文（列表截断、只留未通过的质量检查）注入提示词，LLM 只能引用这些事实输出"结论/证据/风险/建议"。它不参与计算，只做解释和归因辅助。

**⭐Q11 LLM 在统计推断里有什么局限？怎么防幻觉？（JD 优先#5）**
答：局限：① 不能做真正的计算，数值结论必须由代码算；② 对"不确定性"表述不可靠，容易把观察说成因果；③ 会编造不存在的指标/数字。我项目里的防线：上下文只有真实指标快照 + 提示词禁止编造和因果声明 + **可信度信封**（样本量/时间范围/质量状态，低置信度强制降级为"探索性判断"）+ 失败自动降级本地规则。

**Q12 LLM 辅助实验设计你怎么想？**
答：可用在：把业务问题翻译成假设和指标、生成候选实验方案、解释统计结果给业务听、自动化数据洞察（类似我 AIHR 助手的能力）。但要设护栏：实验设计和统计判断（样本量、显著性）必须由人来验证，LLM 只做辅助和解释。

## 五、行为题（JD 的"推动机制落地/协同"）

**⭐Q13 讲一个你推动"用数据说话"的经历。**
答：AIHR 里，业务只问"AI 面试率是不是更高"，我没有直接给一个数字，而是先讲清为什么不能直接比（选择偏差、滞后），再给"调整后差异 + SMD 平衡证据 + 结论边界"，最后给"下一步查哪"的路径——用一套可信的分析框架让业务接受更严谨的结论。这锻炼了我把业务问题翻译成数据问题的能力。

**Q14 和业务有分歧怎么办？**
答：先对齐目标和口径（指标定义），用数据和证据沟通（置信区间而不是单点），承认观察性数据的边界，必要时提出用实验验证——分歧最终靠更好的证据设计解决。
