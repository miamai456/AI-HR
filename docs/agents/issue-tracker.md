# Issue Tracker

This repo tracks work in GitHub Issues:

- Repository: `miamai456/AI-Hiring-Monitor`
- Remote: `https://github.com/miamai456/AI-Hiring-Monitor.git`
- Preferred CLI: `gh`

Skills such as `/to-spec`, `/to-tickets`, `/triage`, and `/implement` should use GitHub Issues unless the user explicitly asks for local markdown or another tracker.

PRs are not treated as a triage request surface by default.
