# Domain Docs

AIHR uses a single-context domain documentation layout.

- Shared project vocabulary lives in the root `CONTEXT.md`.
- Architecture Decision Records live in `docs/adr/`.
- Agent-specific setup notes live in `docs/agents/`.

When a task introduces important project language, update `CONTEXT.md`. When a task makes a decision that will be costly to reverse, add an ADR in `docs/adr/`.
