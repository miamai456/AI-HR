# AIHR 运行与验证

## 前置条件

- Python 3.10+。
- Docker Desktop（仅 Docker 方式需要）。
- PowerShell 示例均在仓库根目录执行。

不要把数据库备份、真实 ATS 数据、`.env`、`.streamlit/secrets.toml` 或 API Key 提交到 Git。

## 本地运行

### 1. 安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

默认配置文件为 `config/config.ini`，它使用项目目录下的 SQLite 并在首次启动时生成合成演示数据。

### 2. 启动 API

```powershell
uvicorn aihr.api.main:app --reload
```

检查：

```powershell
Invoke-RestMethod http://localhost:8000/api/v1/health
```

预期返回数据库状态和后端类型。

### 3. 启动 Dashboard

另开一个已激活虚拟环境的 PowerShell：

```powershell
$env:AIHR_API_URL="http://localhost:8000/api/v1"
streamlit run app/首页.py
```

访问：

- Dashboard：`http://localhost:8501`
- API Docs：`http://localhost:8000/docs`
- Health Check：`http://localhost:8000/api/v1/health`

也可以使用启动脚本：

```powershell
.\scripts\start-dev.ps1
```

脚本会把 API 与 Dashboard 输出写入 `logs/`。

## Docker 运行

Docker 模式启动 MySQL、FastAPI API 和 Streamlit Dashboard：

```powershell
docker compose up --build
```

访问地址与本地模式相同。停止服务：

```powershell
docker compose down
```

删除 MySQL 演示数据卷：

```powershell
docker compose down --volumes
```

注意：`config/config.Online.ini` 中的 Compose 密码是本地演示占位符。部署到任何真实环境时，必须通过密钥管理或环境变量注入强随机密码。

## 配置 AI 分析助手

复制示例文件：

```powershell
Copy-Item .streamlit\secrets.example.toml .streamlit\secrets.toml
```

在 `.streamlit/secrets.toml` 填入自己的服务配置：

```toml
AIHR_ASSISTANT_PROVIDER = "kimi"
AIHR_ASSISTANT_BASE_URL = "https://api.moonshot.ai/v1"
AIHR_ASSISTANT_MODEL = "kimi-k3"
AIHR_ASSISTANT_API_KEY = "replace-with-your-api-key"
```

也可用环境变量临时覆盖：

```powershell
$env:AIHR_ASSISTANT_PROVIDER="kimi"
$env:AIHR_ASSISTANT_BASE_URL="https://api.moonshot.ai/v1"
$env:AIHR_ASSISTANT_MODEL="kimi-k3"
$env:AIHR_ASSISTANT_API_KEY="replace-with-your-api-key"
```

未配置时，AI 助手会使用本地规则分析，仍可解释当前筛选范围内的指标、风险和限制。

## 导入公开职位市场数据

项目支持导入 Kaggle LinkedIn Jobs & Skills 压缩文件。将文件放在本地忽略目录，例如：

```text
data/raw/linkedin_job_postings.csv.zip
data/raw/job_skills.csv.zip
```

只检查压缩包结构：

```powershell
python -m aihr.data_sources.linkedin_kaggle `
  --postings-zip data/raw/linkedin_job_postings.csv.zip `
  --skills-zip data/raw/job_skills.csv.zip `
  --inspect-only
```

先导入小样本：

```powershell
python -m aihr.data_sources.linkedin_kaggle `
  --postings-zip data/raw/linkedin_job_postings.csv.zip `
  --skills-zip data/raw/job_skills.csv.zip `
  --limit 10000
```

这部分数据用于职位市场分析。它不会自动变成真实招聘漏斗或真实候选人效果数据。

## 验证命令

```powershell
pytest
ruff check .
```

测试覆盖：

- 配置文件和环境变量覆盖。
- 固定种子的生成可复现性。
- 推荐、漏斗事件和阶段顺序。
- 植入的选择偏差、版本退化、联系延迟、漂移和未成熟队列。
- `mart_*` 集市契约与幂等刷新。
- Kaggle 压缩 CSV 检查。
- API 响应结构、统一筛选、效果诊断、监控、数据质量和机器学习洞察。

## 常见问题

### `pytest` 提示找不到 FastAPI 或其他依赖

当前 Python 环境没有安装项目依赖。确认已激活 `.venv`，然后重新执行：

```powershell
python -m pip install -e ".[dev]"
pytest
```

### Dashboard 无法连接 API

确认 API 已启动，并检查：

```powershell
Invoke-RestMethod http://localhost:8000/api/v1/health
```

然后确认启动 Dashboard 的终端中：

```powershell
$env:AIHR_API_URL
```

值为 `http://localhost:8000/api/v1`。

### 端口已占用

检查 `8000` 或 `8501` 是否被已有进程占用，停止旧进程或用 `--port` 指定其他端口；若改了 API 端口，也要同步更新 `AIHR_API_URL`。
